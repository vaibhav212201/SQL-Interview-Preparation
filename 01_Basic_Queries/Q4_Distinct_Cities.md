# Q4 - Find All Unique Cities

## Problem

Retrieve all unique cities from the Employees table.

## SQL Query

```sql
SELECT DISTINCT city
FROM Employees;
```

## Explanation

DISTINCT removes duplicate values and returns only unique cities.

## Expected Output

| city |
|------|
| Delhi |
| Noida |
| Mumbai |
| Pune |
| Bangalore |
| Hyderabad |
| Chennai |

## Concepts Used

- SELECT
- DISTINCT
- Removing Duplicates
